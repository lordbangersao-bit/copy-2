# Assets PWA a fornecer

Colocar aqui os ficheiros gráficos abaixo, gerados a partir da **insígnia
institucional já existente** (`public/images/brasao-angola.png` /
`src/assets/insignia-angola.png`). Não usar outro logotipo.

| Ficheiro | Dimensão | Notas |
| --- | --- | --- |
| `icon-192.png` | 192x192 | purpose `any` |
| `icon-512.png` | 512x512 | purpose `any` |
| `icon-192-maskable.png` | 192x192 | maskable (margem de segurança ~10%) |
| `icon-512-maskable.png` | 512x512 | maskable (margem de segurança ~10%) |
| `apple-touch-icon.png` | 180x180 | fundo opaco (iOS não suporta transparência) |
| `screenshot-desktop.png` | 1280x800 | form_factor `wide` |
| `screenshot-mobile.png` | 720x1280 | form_factor `narrow` |

Enquanto não existirem, a instalação continua a funcionar através do
`favicon.ico`, mas a experiência de instalação não será a "profissional"
completa (sem ícone maskable nem pré-visualizações na store do browser).
